# ICs — design blocks by subsystem

Reusable KiCad 10 schematic **design blocks** for ICs, organized by subsystem. Each block contains
the IC together with its supporting passives and connections (the full application circuit), plus a
README explaining what the IC does and how the block is wired. Datasheets live in
[`component_library/datasheets-only/ICs/`](../../datasheets-only/ICs/).

| Subsystem | Folder | Contents |
|-----------|--------|----------|
| TT&C (Telemetry, Tracking & Command) | [`TT&C/`](TT%26C/) | Radios, radio power, antenna balun and ground-station RF switching, taken from SAMWISE |
